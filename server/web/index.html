Every number here is supplied by the player's own client. The addon writes a file, an uploader sends it. Nothing is verified against the game server, because nothing can be. Impossible values are rejected; dishonest ones are not detectable. Treat this as a scoreboard among friends, not an audited ranking.

LevelPace · levels per hour, not XP per hour — so a level 20 and a level 78 are compared fairly.
