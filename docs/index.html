This ranks LevelPace users, not the server. Nobody appears here unless they installed the addon, switched sharing on, and ran the uploader. A 100 parse means fastest among the people on this board — it is not a claim about anyone else. There is no alternative: time-per-level is not recorded anywhere server-side, so this data exists only because the addon measured it while someone played.

Every number is supplied by the player's own client. The addon writes a file, an uploader sends it. Nothing is verified against the game server, because nothing can be. Impossible values are rejected; plausible lies are not detectable. Treat this as a scoreboard among friends, not an audited ranking.

LevelPace · levels per hour, not XP per hour — so a level 20 and a level 78 are compared fairly.
